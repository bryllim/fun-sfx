# Recording rights

The MIT license covers FUN SFX code and documentation only. It does **not**
grant rights to the audio/video recordings under `assets/`, including WAV
audio extracted from MP4 files.

These files were supplied from a local folder named `Mini SFX Pack - JOWS`.
The folder contained no license, attribution manifest, or source URLs. The
supplier confirmed that recording rights are unconfirmed. No authorship or
permission is inferred from filenames, artist/game/show references, or claims
such as “free to use” and “no copyright”. The folder name is provenance, not
an assertion of ownership or attribution.

All recordings are cataloged with `license_status: unverified`, no asserted
license, no asserted author, and no asserted source URL. Original filenames
and SHA-256 hashes are retained to help future provenance work. Extracted
audio inherits the original recording's unverified status.

The complete local pack includes all supplied files for the requested
inventory and editing workflow. It is not a rights-cleared open-source audio
release. Before publicly redistributing recordings, establish permission and
record the author, source URL, license, and any required attribution, or omit
those recordings from the public release. The code and documentation can be
published under MIT separately.
